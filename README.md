# BarberFlow 💈

**Uma experiência moderna para uma barbearia, com foco em estilo, praticidade e identidade visual.**

O BarberFlow é um projeto de desenvolvimento front-end criado para apresentar os serviços de uma barbearia de forma elegante, moderna e responsiva. A interface combina um design escuro com detalhes dourados, valorizando a identidade visual e proporcionando uma navegação intuitiva.

O projeto também conta com um formulário de agendamento integrado ao WhatsApp, permitindo que o cliente envie seus dados e solicite um horário diretamente pelo aplicativo.

## ✨ Funcionalidades

- **Página inicial:** apresentação da barbearia com destaque para sua identidade visual.
- **Seção de serviços:** exibição dos serviços oferecidos, com duração, preços e acesso ao agendamento.
- **Perfil do barbeiro:** apresentação do profissional e de suas especialidades.
- **Galeria de cortes:** área dedicada à exibição de trabalhos e estilos.
- **Seção de contato:** informações de localização, contato e horário de funcionamento.
- **Agendamento via WhatsApp:** formulário para preenchimento do nome, telefone e serviço desejado.
- **Modal de agendamento:** interface para solicitar um horário sem sair da página.
- **Layout responsivo:** adaptação da interface para diferentes tamanhos de tela.
- **Efeitos visuais:** transições e interações para enriquecer a experiência de navegação.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação semântica do conteúdo.
- **CSS3:** estilização, layout, animações e responsividade.
- **JavaScript:** interatividade, controle do modal e integração com o WhatsApp.

## 🎨 Identidade visual

O projeto utiliza uma paleta de cores inspirada em uma estética premium:

- **Preto e tons escuros:** elegância e sofisticação.
- **Dourado (`#C89B5C`):** destaque para botões, detalhes e elementos interativos.
- **Branco e cinza:** legibilidade e equilíbrio visual.

## 📱 Agendamento pelo WhatsApp

O formulário permite que o visitante informe seus dados e selecione um serviço. Em seguida, o sistema prepara uma mensagem com as informações preenchidas e direciona o usuário para o WhatsApp da barbearia.

Para utilizar o recurso em um ambiente real, é necessário configurar o número correto do WhatsApp e atualizar as informações de contato da página.
